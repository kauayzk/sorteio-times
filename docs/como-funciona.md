# Como funciona cada modo

Todos os modos ficam em **Monte o sorteio**, em abas. Os nomes digitados ficam salvos só no
navegador (o botão **Limpar tudo** apaga).

## WEAK GG — cabeças de chave e estrelas

Para 4 times equilibrados de 4 jogadores.

1. Preencha o nome de cada time e o **cabeça de chave** dele (não entra no sorteio).
2. Preencha as **8 estrelas** e os **4 jogadores**.
3. **Iniciar sorteio.**

O sorteio tem 3 rodadas, e em cada uma a ordem dos times é sorteada de novo:

- Rodadas 1 e 2: uma estrela para cada time (todo time termina com exatamente duas).
- Rodada 3: um jogador para cada time.

**Colar lista:** o botão abre uma janela para colar tudo de uma vez (times no formato
`Time - Cabeça de chave`, um por linha). Também dá para colar uma lista direto em qualquer campo:
ela se espalha pelos campos seguintes. Numeração, marcadores e `@` são removidos sozinhos.

## Padrão — só os nomes

1. Escolha de **2 a 8 times**.
2. Cole os nomes (um por linha ou separados por vírgula, até 64).
3. Se quiser, dê nome aos times (sem nome vira `TIME 01`, `TIME 02`…).

A cada rodada cada time recebe um jogador, com a ordem dos times sorteada de novo. Se a divisão
não for exata (ex.: 14 nomes em 4 times), quem fica com um jogador a mais também é sorteado — e,
durante o sorteio, todos os times mostram o mesmo número de vagas, para não entregar isso antes.

## Confrontos — chaveamento

1. Cole os nomes dos times (de **2 a 32**).
2. Se quiser, o nome do campeonato.
3. **Sortear confrontos.**

O chaveamento é eliminatório simples, com 2, 4, 8, 16 ou 32 vagas. Se o número de times não
fechar uma dessas quantidades, sobram vagas sem adversário: esses times avançam direto (folga).
O sorteio põe um time em cada jogo da 1ª fase (lado A) e depois completa os adversários (lado B),
então quais jogos ficam com folga também é sorteado.

No final aparece o chaveamento completo, com as duas metades se encontrando na final.

- **Clique no vencedor** de cada jogo para ele avançar; clique de novo para desfazer.
- Um resultado só vale enquanto os dois times do jogo estão definidos: se você mudar um jogo
  anterior, os jogos que dependiam dele voltam a ficar em aberto.
- Ao definir a final, o campeão aparece na caixa **CAMPEÃO**.
- Os resultados ficam salvos no navegador. **Abrir último chaveamento** (na aba Confrontos)
  reabre de onde parou.

## No palco do sorteio

| Controle | O que faz |
|---|---|
| **REVELAR** / Espaço / Enter | Revela o próximo nome |
| **Auto** | Revela sozinho, um após o outro |
| **1x / 1,5x / 2x / 3x** (tecla V) | Velocidade de todo o sorteio; fica salva |
| **Tela cheia** (tecla F) | Modo transmissão: os controles somem quando o mouse para |
| **Som** | Liga/desliga os efeitos sonoros |
| **#código** | Copia o código do sorteio |
| **Sair** (Esc) | Volta para o formulário |

## Depois do sorteio

- **Baixar imagem / Copiar imagem:** imagem do resultado no visual da página.
- **Copiar resultado:** texto com os times (ou os jogos, com vencedores e campeão), o código do
  sorteio e um link que abre a verificação já preenchida.
- **Sortear de novo:** mesmo nomes, nova semente.
- **Ver log do sorteio:** cada escolha e entre quais nomes ela foi feita.
